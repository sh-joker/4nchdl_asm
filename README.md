# 4nchdl_asm
自作16bitCPU用HTMLアセンブラです

## 概要
これは4NC情報通信プロジェクト「HDLによる論理回路設計」用のアプリケーションです．

バグ報告はIssue，または学番メール [22nc049 at ms.dendai.ac.jp] までお願いします．\
(卒業以降はメールを見る頻度が激減しますがご了承ください．)

## 使い方
asm-converter フォルダをダウンロードしてご利用ください．

フォルダ内の index.html がアプリケーション本体です．命令セットとアセンブリを入力することで命令後のバイナリ出力，およびHEX出力が得られます．

命令セットは実行ページを閉じると保存されませんので，CSVファイルで保存し，次回からはファイルインポートからの開始をおすすめします．\
それが面倒な方は初期値の書き換えがおすすめです．

初期値はニーモニックをKey，オペコードをValueとしたObjectで定義しており asm-converter/js/script.js の88行目で代入しています．\
20行目のISA_ORIGINAL変数を自身の命令セットに合わせて修正し，88行目の代入をISA_ORIGINALとすれば変更完了です．
